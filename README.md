# FTL for PS Vita

PS Vita port work for Project Wormhole / Tachyon.

This repository is the working port tree. User-owned FTL assets such as `ftl.dat` are not included.

## Current status
- C++17 migration prototype added
- Platform / input / rendering / data / game-state boundaries established
- Vita-specific backend and real `ftl.dat` / BXML parsing are next

Prototype archive: `prototype/vita-wormhole-port-prototype.zip`
